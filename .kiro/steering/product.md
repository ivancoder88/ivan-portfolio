# Product

Ivan Iviček's personal portfolio website — a bilingual (English/Croatian) single-page application that showcases his professional background as a software developer and civil engineer.

## Purpose
- Present Ivan's skills, work experience, and services to potential employers and clients
- Provide a contact form for inbound inquiries
- Include a password-protected admin dashboard for managing site content and viewing messages

## Key Features
- Public homepage with sections: Hero, Services, Timeline, Resume, Skills, Tech Stack, Contact, Footer
- Dark/light theme toggle (persisted in localStorage)
- Language toggle: English ↔ Croatian
- Scroll-reveal animations
- Contact form (messages stored server-side as JSON)
- Admin dashboard: login/register, message inbox, page content customization
- SSR (Angular Universal) for SEO and performance

## Target Audience
Recruiters, clients, and collaborators viewing Ivan's professional profile.
